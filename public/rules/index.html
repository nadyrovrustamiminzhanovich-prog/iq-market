Общие правила безопасности IQ-Market & Taxi

1. Для пользователей Маркета

  • Никогда не переводите предоплату за товар.
  • Проверяйте товар в светлом людном месте.
  • Не переходите по подозрительным ссылкам "для оплаты" в чатах.

2. Для водителей Такси

  • Курение в салоне строго запрещено.
  • Автомобиль должен быть чистым и в исправном состоянии.
  • Разговоры на отвлеченные темы с Пассажиром без его согласия не приветствуются.
  • Категорически запрещено использование чужого аккаунта.

3. Для пассажиров Такси

  • Запрещено распитие спиртных напитков в салоне автомобиля.
  • Запрещена перевозка крупногабаритного багажа без предварительного согласования.
  • Вежливое отношение к Водителю обязательно.

4. Модерация и блокировки

За любое нарушение (хамство, обман, накрутка отзывов) аккаунт блокируется ПОЖИЗНЕННО по номеру телефона и ID устройства.
