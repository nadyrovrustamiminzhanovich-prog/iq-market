Правила безопасности

Общие правила безопасности IQ-Market & Taxi

1. Для пользователей Маркета

  • Никогда не переводите предоплату за товар.
  • Проверяйте товар в светлом людном месте.
  • Не переходите по подозрительным ссылкам "для оплаты" в чатах.

2. Для водителей Такси

  • Курение в салоне строго запрещено.
  • Автомобиль должен быть чистым и в исправном состоянии.
  • Разговоры на отвлеченные темы с Пассажиром без его согласия не приветствуются.
  • Категорически запрещено использование чужого аккаунта.

3. Для пассажиров Такси

  • Запрещено распитие спиртных напитков в салоне автомобиля.
  • Запрещена перевозка крупногабаритного багажа без предварительного согласования.
  • Вежливое отношение к Водителю обязательно.

4. Модерация и блокировки

За любое нарушение (хамство, обман, накрутка отзывов) аккаунт блокируется ПОЖИЗНЕННО по номеру телефона и ID устройства.

1. Маркет пайдаланушылары үшін

  • Тауар үшін ешқашан алдын ала төлем (алдын ала ақша) аудармаңыз.
  • Тауарды жарық әрі адам көп жерде тексеріңіз.
  • Чаттардағы "төлем жасау үшін" күмәнді сілтемелерге өтпеңіз.

2. Такси жүргізушілері үшін

  • Салонда темекі шегуге қатаң тыйым салынады.
  • Автокөлік таза әрі жарамды күйде болуы тиіс.
  • Жолаушының келісімінсіз басқа тақырыптарда сөйлесу құпталмайды.
  • Бөтен аккаунтты пайдалануға қатаң тыйым салынады.

3. Такси жолаушылары үшін

  • Автокөлік салонында ішімдік ішуге тыйым салынады.
  • Алдын ала келісусіз ірі көлемді жүктерді тасымалдауға тыйым салынады.
  • Жүргізушіге сыпайы қарау міндетті.

4. Модерация және бұғаттау

Кез келген ереже бұзушылық үшін (дөрекілік, алдау, пікірлерді қолдан көбейту) аккаунт телефон нөмірі және құрылғы ID-йі бойынша ӨМІРЛІККЕ бұғатталады.

1. Маркет пайдиланғучилири үчүн

  • Мал үчүн һеч қачан алдин-ала ақча (алдин ала төләм) әвитмәң.
  • Мални йоруқ вә одам көп жайда тәкшүрүң.
  • Чатлардики "төләм қилиш үчүн" гүмәнлик улинишларға кирмәң.

2. Такси шопурлири үчүн

  • Салонда тамака чекишкә қәтъий чәклиниду.
  • Автомобиль таза вә саз һаләттә болуши керәк.
  • Йолоғучиниң қошулушисиз бөлөк мавзуларда созлишиш хош көрүлмәйду.
  • Бөтән аккаунтни ишлитишкә қәтъий чәклиниду.

3. Такси йолоғучилири үчүн

  • Автомобиль салонида һарақ-шарап ичишкә чәклиниду.
  • Алдин-ала келишмәсдин йерим-йирик йүкләрни тошушқа чәклиниду.
  • Шопурға сипайилиқ билән муамилә қилиш мәжбурий.

4. Модерация вә тосушлар

Һәр қандақ қаидә бузуш (қопаллиқ, алдамчилиқ, пикирләрни сохта купайтиш) үшін аккаунт телефон номури вә үскунә ID-си бойичә МӘҢГҮЛҮККӘ тосулиду.
